# Phonon Reader

A Chrome MV3 extension that reads web pages aloud using [Ollama's](https://ollama.com) `phonon` text-to-speech model — fully local, no cloud TTS.

![Chrome](https://img.shields.io/badge/Chrome-116%2B-blue) ![Ollama](https://img.shields.io/badge/Ollama-0.40.9%2B-green)

## Features

- **Read the whole page** or just a **text selection** (toolbar popup or right-click context menu)
- **On-page control widget** (top-right): status, pause/resume, stop — no need to keep the popup open
- **Live sentence highlighting** — the sentence currently being spoken is highlighted in the page via the CSS Custom Highlight API
- **Long-page support** — text is split into sentence-aligned chunks that fit the speech endpoint's 4,096-character input cap and played back seamlessly
- **Local & private** — audio is generated by your own Ollama server; nothing leaves your machine

## Prerequisites

1. **Ollama 0.40.9+** running locally ([download](https://ollama.com/download))
2. The phonon model:

   ```sh
   ollama pull phonon
   ```

3. **CORS for browser extensions.** The easiest path: in the Ollama app settings, enable **browser integration** (the app then allows all origins). Alternatively, start the server with:

   ```sh
   OLLAMA_ORIGINS='chrome-extension://*' ollama serve
   ```

   > Note: phonon requires Apple Silicon.

## Build & install

```sh
npm install
npm run build
```

Then in Chrome:

1. Open `chrome://extensions`
2. Enable **Developer mode**
3. Click **Load unpacked** and select the `dist/` folder

## Usage

1. Open any article page
2. Click the Phonon Reader toolbar icon → **Read page**, or select text first → **Read selection** (or right-click the selection → _Read selection aloud_)
3. Use the widget in the page's top-right corner (or the popup) to pause/resume/stop

## How it works

```
popup / context menu ──▶ service worker (orchestrator)
                          ├─ injects extractor: text + DOM node map
                          ├─ plans sentence-aligned chunks (≤4,000 chars)
                          ├─ port ──▶ offscreen document
                          │             fetches WAV per chunk from
                          │             POST /v1/audio/speech (24 kHz mono)
                          │             plays via <audio>, reports progress
                          └─ maps playback position ──▶ sentence highlight
                                     ──▶ CSS Custom Highlight API in page
```

- Speech models reject `/api/chat`, so the extension uses the OpenAI-compatible `/v1/audio/speech` endpoint directly.
- phonon streams audio with placeholder WAV size fields; the offscreen document patches the header so durations are correct.
- The MV3 service worker can't play audio, hence the `chrome.offscreen` document; keep-alive pings prevent worker idle-out during long sessions.
